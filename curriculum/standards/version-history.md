# Curriculum Version History

## Versioning policy

Curricula use semantic versioning:

- **Major** versions change the structure, teaching philosophy, or scope.
- **Minor** versions add lessons, leader resources, or substantial teaching support.
- **Patch** versions correct wording, references, formatting, accessibility, or links without changing the lesson’s core meaning.

Each curriculum should display its version in the curriculum overview and record significant revisions here or in a curriculum-specific changelog.

- Established review and publication requirements for future curriculum releases.

## Release checklist

Before changing a curriculum version:

1. Confirm Scripture references and quotations.
2. Review theology, historical claims, and cultural applications.
3. Confirm participant and leader materials remain aligned.
4. Test website, print, mobile, accessibility, and navigation behavior.
5. Record the reason for the version change.
6. Preserve prior release notes so churches can identify what changed.
