# No Labels, Designed by God Curriculum Framework

This directory defines the shared standards, components, and templates used to create and revise ministry curriculum.

## Purpose

Every curriculum should help people:

1. Understand what Scripture says.
2. Interpret it faithfully.
3. Live it as followers of Jesus.
4. Help another person grow.

> The goal of a study is not to finish a lesson. The goal is to become more like Jesus and help others do the same.

## Required curriculum package

Each completed lesson should provide:

- Participant Guide
- Expanded Leader Guide
- Condensed Leader Notes
- Teaching presentation outline or slides
- Printable handout
- Resource appendix or verified resource connections

## Core lesson flow

**Welcome → Read → Learn → Discuss → Apply → Pray → Go**

## Development workflow

1. Define the lesson’s big idea and primary Scripture.
2. Build the participant guide first.
3. Build the expanded leader guide around the same truth and application.
4. Create condensed notes, handout, and presentation from the approved guides.
5. Review Scripture, theology, historical claims, cultural claims, and safety needs.
6. Test website, mobile, accessibility, print, internal links, and saved-state behavior.
7. Record the curriculum version and release notes.

## Internal publication test

Before a lesson is published, ask:

> If a small-group leader with limited teaching experience picked this up tonight, could they faithfully lead people toward Jesus?

Also ask:

- Is Scripture controlling the lesson rather than decorating it?
- Does the lesson point people toward Jesus and faithful obedience?
- Are difficult questions handled honestly and humbly?
- Are vulnerable people protected through appropriate safety guidance?
- Do the participant and leader resources teach the same central truth?

If the answer to any essential question is no, the lesson is not complete.
