# No Labels, Designed by God Curriculum Framework

This directory defines the shared standards, components, and templates used to create and revise ministry curriculum.

## Purpose

Every curriculum should help people:

1. Understand what Scripture says.
2. Interpret it faithfully.
3. Live it as followers of Jesus.
4. Help another person grow.

> The goal of a study is not to finish a lesson. The goal is to become more like Jesus and help others do the same.

## Directory Structure

- `standards/` — teaching, curriculum, leader, writing, and versioning standards
- `components/` — reusable lesson sections and required content fields
- `templates/` — participant, leader, presentation, handout, and leader-notes templates

## Required Curriculum Package

Each completed lesson should provide:

- Participant Guide
- Expanded Leader Guide
- Condensed Leader Notes
- Teaching Slides outline
- Printable Handout
- Resource Appendix

## Core Lesson Flow

**Welcome → Read → Learn → Discuss → Apply → Pray → Go**

## Internal Publication Test

Before a lesson is published, ask:

> If a small-group leader with limited teaching experience picked this up tonight, could they faithfully lead people toward Jesus?

If the answer is no, the lesson is not complete.
