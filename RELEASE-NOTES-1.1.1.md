# No Labels, Designed by God — Version 1.1.1

Prepared: August 10, 2026

Version 1.1.1 is a maintenance checkpoint for the ministry content, game improvements, accessibility work, and repository cleanup completed after Version 1.1.0.

## New and expanded studies

- Added the five-lesson When Preferences Become Idols series
- Added the After the Benediction discipleship series
- Organized book-by-book studies under one collection
- Added studies through Philippians and 1 John alongside James
- Added direct Bible Gateway links for study Scripture references

## Bible Tic-Tac-Toe

- Added the game to the public Game Center
- Made players select a square and answer its question correctly to claim it
- Connected the game to the larger question pool
- Added Scripture references to reinforce the correct answers
- Added a persistent exit control
- Improved turn advancement for leaders and hosts

## Ministry experience

- Added the founder profile and teaching photo
- Streamlined homepage content to reduce unnecessary length
- Diversified repeated homepage study recommendations
- Simplified the shared footer
- Added the merchandise Coming Soon preview
- Clarified podcast preview availability

## Accessibility and quality

- Improved game-button contrast
- Corrected tournament heading hierarchy
- Added pull-request coverage to the accessibility audit
- Strengthened repository-completion and site-quality checks
- Improved version-label auditing so only outdated releases are reported
- Moved generated audit reports to workflow artifacts
- Removed obsolete pre-1.0 build, version, and sprint files

## Installable site

- Advanced the service-worker cache checkpoint to Version 1.1.1
- Preserved responsive phone, tablet, laptop, presentation, and offline behavior

## Architecture boundary

Personal progress and notes remain stored on the visitor's device. Secure accounts, cross-device synchronization, online multiplayer, and cloud collaboration require a protected backend and are not represented as available in this release.
