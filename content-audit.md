# Bible Game Content Audit

Status: Active for Version 1.0

## Review standard

Every question should be checked for:

- Biblical accuracy
- Correct person, title, place, event, and sequence
- A clear answer with no equally valid alternative
- Age-appropriate wording
- Consistent capitalization and punctuation
- Scripture reference accuracy where a reference is shown
- Translation consistency in Finish the Verse
- No accidental duplicate or near-duplicate questions within the same audience bank

## Version 0.9.4 review tools

- The shared game wrapper applies approved wording corrections during play.
- Hosts can use **Flag Question** to save a game, audience, question, and review note on the current device.
- Flagged questions remain in local storage so real-world family and church testing can feed the final audit.
- Version 1.0 will not be declared complete until the source question banks themselves are reviewed and corrected.

## Corrections now applied during Game Center play

### Who Am I?

- Agrippa is described as a king rather than a governor.
- Joseph of Arimathea is described as asking Pilate for Jesus' body rather than secretly taking it.
- The John and Revelation clue now identifies the authorship connection as traditional identification.
- Phoebe's clue now uses the explicit Romans 16 commendation rather than stating as fact that she delivered the letter.

These runtime corrections protect current play while the full source-bank review continues.

## Game review order

### 1. Who Am I? — First pass active

- Verify names, titles, government roles, family relationships, and ministry roles.
- Review traditional-attribution wording where Scripture does not explicitly name an author.
- Check all five audience banks for duplicate identities and clues that allow multiple answers.

### 2. Finish the Verse — Pending full translation pass

- Choose and document the translation used by each question bank.
- Compare every verse ending and reference against that translation.
- Avoid mixing wording from different translations in one question.

### 3. Scripture or Suspicion — Pending

- Verify every true statement and every misconception.
- Make false options clearly false without becoming silly or misleading.
- Add a supporting Scripture reference during the review process.

### 4. Bible Jeopardy — Pending

- Verify clue values match difficulty.
- Check category labels, answers, names, dates, places, and events.
- Remove clues that allow multiple reasonable responses.

### 5. Lightning Round — Pending

- Keep questions short enough for timed play.
- Verify that rapid-response wording still has one clear answer.

### 6. Memory Match — Pending

- Verify every pair has a direct and understandable relationship.
- Avoid pairs that could reasonably match more than one card.

## Audience balance

Each game should be reviewed separately for Preschool, Kids, Teens, Adults, and Family. Preschool questions should use familiar people, concrete wording, and limited answer choices. Adult questions may include less familiar people and events but should remain clear rather than obscure for obscurity's sake.

## Release rule

Version 1.0 should not be labeled complete until all six games and all five audience banks have been reviewed and marked passed.
